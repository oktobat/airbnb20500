server에 설치한 라이브러리
express : Node.js 환경에서 웹 서버를 쉽게 구축하게 해주는 핵심 프레임워크
          클라이언트(React)에서 들어오는 요청을 받아서 적절한 함수로 연결(라우팅)하고, 처리 결과(JSON)를 다시 보내주는 역할을 맡음.
mysql2 : Node.js 서버와 MySQL 데이터베이스를 연결해 주는 다리
         서버 코드 안에서 SELECT, INSERT 같은 SQL 쿼리를 직접 실행하고, DB에서 조회한 데이터를 JavaScript 객체 형태로 받아올 때 사용함
dotenv : DB 비밀번호, 토큰 암호화 키 등 민감한 보안 정보를 .env라는 파일로 분리하여 관리하게 해줌.
         소스 코드가 GitHub 등에 공개되더라도 비밀번호나 보안 키가 노출되지 않도록 process.env.DB_PASS 형태로 숨겨서 불러올 수 있게 도와줌
cors : 다른 포트(도메인) 간의 데이터 요청을 허용해 주는 미들웨어
       브라우저는 보안상 http://localhost:5173(React)에서 http://localhost:5000(Express)으로 데이터를 요청하면 기본적으로 차단함. cors 설정을 통해 "이 프론트엔드는 안전하니 요청을 허용해라"라고 서버가 허가해 주게 됨.
bcrypt : 비밀번호를 복호화(원래대로 되돌리기)할 수 없는 문자열로 강력하게 암호화(해시)함
         사용자가 입력한 1234라는 비밀번호를 $2b$10$e7x... 같은 문자열로 바꿔 DB에 저장합니다. 로그인 시에는 입력받은 비밀번호를 똑같이 변환하여 DB의 암호화된 값과 비교해 맞는지만 검증함.
jsonwebtoken : 로그인 상태를 증명하는 전자 암호화 토큰(유전자 카드)을 생성 및 검증함
       사용자가 로그인에 성공하면 서버가 암호화된 토큰(JWT)을 발급해 줌. 클라이언트는 이 토큰을 저장해 두었다가, 이후 마이페이지 조회 등의 요청을 할 때 헤더에 실어 보내어 "나 로그인한 사람 맞아"라고 인증함.
nodemon : 서버 코드를 수정하고 저장할 때마다 서버를 자동으로 껐다 켜주는 개발 전용 도구
       원래 Node.js는 코드를 수정하면 Ctrl + C로 서버를 끄고 node index.js로 다시 켜야 함. nodemon을 쓰면 파일 저장(Ctrl + S) 즉시 수정 사항이 적용되므로 개발 속도가 훨씬 빨라짐
